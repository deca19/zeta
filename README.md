## AI 켜기 (복붙 2번)
1. 첫 화면의 **🚀 AI 켜기** → **구글 키 만들러 가기**
2. Create API key → 복사 → 돌아와서 붙여넣기. 끝 (키 종류 자동 인식 + 연결 확인)
3. (선택) OpenRouter 키도 붙여넣으면 한도에 걸려도 다른 AI로 자동으로 넘어가요

키는 그 폰 브라우저에만 저장돼요.
